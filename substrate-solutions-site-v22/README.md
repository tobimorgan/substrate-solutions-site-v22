# Substrate Solutions Limited — Prop Website

Responsive static website for Substrate Solutions Limited, refreshed to match the supplied purple/slate corporate logo and selected homepage design.

## Included
- Supplied company logo integrated throughout the site
- Purple/slate brand palette sampled from the supplied logo
- Custom SVG background texture using the logo colours
- Responsive navigation and mobile layout
- Hero, services, projects, approach, Lagos positioning, company and contact sections
- Supplied project photography integrated into the portfolio
- Demo contact form

## Before publishing
Replace the demo phone number, email address, company/legal information, certifications, project claims and any other unverified details with real information. Connect the contact form to your preferred email/CRM.

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.
